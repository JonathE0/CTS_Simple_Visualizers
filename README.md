# CTS Simple Visualizers

Interactive Python visualizers for learning CubeSat sensing and attitude control. Each application runs locally and opens in your browser.

- [Coarse Sun Sensor](Coarse%20Sun%20Sensor/README.md): explore six ideal cosine Sun sensors on a rotating 1U CubeSat.
- [Manual Throttle Control](Manual%20Throttle%20Control/README.md): use three reaction-wheel momentum throttles to detumble a CubeSat and point +Z toward the Sun.

See each folder for setup instructions and model assumptions. Python 3.10 or newer is required; no additional Python packages are needed.
